# JavaScript labs

Hands-on JavaScript examples covering web applications, databases, and npm package workflows.

| Lab | Purpose |
| --- | --- |
| [Express MongoDB](./express-mongodb/README.md) | Run an Express application backed by MongoDB |
| [npm](./npm/README.md) | Work with npm packages and GitHub Actions permissions |

## Requirements

- Docker with Compose v2
- GNU Make
- Node.js and npm where required by the lab

Each lab has its own README. Run `make help` where a Makefile is provided to see the available commands.
